# Getting help

- **How do I…?** Start with the [documentation](https://koneb71.github.io/pyloggle/). The app's
  **Help** page links to it too, and shows the search syntax and keyboard shortcuts.
- **Something does not work as the docs say.** Open a
  [bug report](https://github.com/koneb71/pyloggle/issues/new/choose) with the version, how
  you installed it and the steps to reproduce.
- **An idea or a missing feature.** Open a
  [feature request](https://github.com/koneb71/pyloggle/issues/new/choose) that describes
  the problem you want solved.
- **A security problem.** Do not open an issue; see [SECURITY.md](SECURITY.md).

Pyloggle is maintained in spare time. There is no paid support, and answers may take a few
days. Searching the [existing issues](https://github.com/koneb71/pyloggle/issues?q=is%3Aissue)
first often finds an answer sooner.
