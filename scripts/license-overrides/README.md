# License overrides

Some packages ship without a license file in their own folder. For those, the license text is
kept here, named after the package (`/` replaced by `__`), and `scripts/third_party_licenses.py`
uses it. Each file is the upstream text, unchanged.

| File | Package | Source |
|---|---|---|
| `victory-vendor.txt` | victory-vendor (used by recharts) | https://github.com/FormidableLabs/victory/blob/main/LICENSE.txt |
